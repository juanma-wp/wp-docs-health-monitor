Positives

  • The doc correctly describes the Version 2 requirement to use useBlockProps() in the edit implementation — this matches the JSDoc in use-block-props/index.js: 'Use of this hook on the outermost element of a block is required if using API >= v2.'
  • The doc correctly describes the Version 2 requirement that useBlockProps.save() must be called explicitly for saved markup — this matches useBlockProps.save = getBlockProps in both index.js and index.native.js.
  • GAP: The block.json schema constrains apiVersion to "const": 3, meaning only version 3 is valid per the schema. The doc describes versions 1, 2, and 3 as all valid choices, but does not mention this schema-level constraint. Developers setting apiVersion: 1 or apiVersion: 2 in block.json will get schema validation errors.
