Update the add_filter example for block_bindings_source_value to declare 5 accepted arguments instead of 2.

  • Change add_filter( 'block_bindings_source_value', 'wpmovies_format_visualization_date', 10, 2 ) to add_filter( 'block_bindings_source_value', 'wpmovies_format_visualization_date', 10, 5 )
  • Update the callback signature to accept all 5 parameters: function wpmovies_format_visualization_date( $value, $name, $source_args, $block_instance, $attribute_name )

Add a version note to the core/image row in the 'Compatible blocks and their attributes' table clarifying that caption requires WordPress 6.9 or the Gutenberg plugin.

  • The WP 6.8 snapshot in gutenberg_get_block_bindings_supported_attributes (lib/compat/wordpress-6.9/block-bindings.php) only lists id, url, title, alt for core/image
  • caption is added by the compat filter in the same file (lines 14–16) and is natively present in get_block_bindings_supported_attributes in src/wp-includes/block-bindings.php (WP 6.9+)
  • Change the table row to: | core/image | id, url, title, alt, caption (6.9+) | or add a footnote stating caption was added in WordPress 6.9

Positives

  • The documentation correctly states that register_block_bindings_source() should be called from a handler attached to the init hook — this matches the PHPDoc in src/wp-includes/block-bindings.php which explicitly states 'Note that register_block_bindings_source() should be called from a handler attached to the init hook.'
  • The block_bindings_source_value filter parameters (value, name, source_args, block_instance, attribute_name) are accurately documented and match the apply_filters call in WP_Block_Bindings_Source::get_value() in src/wp-includes/class-wp-block-bindings-source.php.
  • GAP: The getFieldsList function receives a { select, context } object (as shown in getBlockBindingsSourceFieldsList in packages/blocks/src/store/private-selectors.ts), but the doc's getFieldsList section does not document these parameters at all — developers implementing getFieldsList would not know what arguments are available to them.
