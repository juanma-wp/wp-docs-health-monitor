Positives

  • The useRefEffect signature documented — useRefEffect( ( element ) => { ... }, [] ) — correctly matches the exported signature useRefEffect(callback: (node: TElement) => (() => void) | void, dependencies: DependencyList), including the cleanup-function return pattern and the dependency array.
  • The doc's description of useRefEffect behaviour ('will call the given callback if the ref changes in addition to any dependencies passed') accurately reflects the implementation, which uses useCallback keyed on dependencies and calls the callback whenever node is non-null.
  • GAP: The doc imports useRefEffect from @wordpress/element, but the symbol is actually exported from @wordpress/compose (as shown in the extracted symbols section). Developers copying the import verbatim will get a runtime error because useRefEffect does not exist in @wordpress/element.
