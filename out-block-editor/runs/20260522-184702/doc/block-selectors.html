Positives

  • The doc's description of the selectors.css property — accepting either a string or an object with a root key — is accurately reflected in the block.json schema, which defines css as a oneOf between a plain string and an object with a root string property.
  • The doc's enumeration of supported feature selectors (border, color, typography, spacing, dimensions) matches the properties listed under selectors in the block.json schema, including their oneOf string-or-object shapes.
  • GAP: The block.json schema's selectors.typography object supports subfeature keys fontFamily, fontSize, fontStyle, fontWeight, lineHeight, letterSpacing, textDecoration, textIndent, and textTransform, but the doc only illustrates text-decoration as a subfeature example. Developers would benefit from knowing the full list of supported typography subfeature selector keys.
