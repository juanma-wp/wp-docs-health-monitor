✅ No issues found.

Positives

  • The wp_unique_id_from_values() function is correctly documented as available since WordPress 6.8 and its signature (array $data, string $prefix = '') matches the source exactly (function wp_unique_id_from_values( array $data, string $prefix = '' ): string).
  • The getServerState() and getServerContext() functions are accurately described: both return deep clones of server-rendered values and are updated on actions.navigate() without affecting the values returned by store() / getContext(), which matches the source implementations in store.ts and scopes.ts.
  • GAP: The watch export (aliased from @preact/signals effect) returns a cleanup/unsubscribe function, as noted in its JSDoc ("Returns a cleanup function to stop watching"). The documentation example does not capture or use this return value, which could matter for developers who need to stop watching (e.g., in data-wp-init teardown scenarios). The doc should mention that watch() returns an unwatch function.
