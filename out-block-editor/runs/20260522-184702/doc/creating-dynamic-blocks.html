Creating dynamic blocks

Positives

  • The doc correctly states that the render_callback receives block attributes and content as arguments — the source code confirms this signature in the inline PHPDoc: @param array $attributes Block attributes. @param string $content Block default content. @param WP_Block $block Block instance.
  • GAP: The doc's PHP example uses wp_get_recent_posts() to fetch the latest post, but the modern recommended approach is register_block_type_from_metadata() with a render field pointing to a PHP template file (supported since WP 6.1, confirmed in register_block_type_from_metadata source). Developers following the doc's pattern will miss this simpler, metadata-driven alternative.
  • The doc correctly notes that the save function should return null for dynamic blocks to skip markup validation — this is consistent with how WordPress handles blocks whose render_callback is set, as confirmed by the render_block implementation in blocks.php.
