Positives

  • The doc correctly describes the namespace attribute as a special Query Loop attribute used purely for variation scoping — the code in build_query_vars_from_query_block confirms namespace is never read by the query-building logic, consistent with the doc's statement that 'it really doesn't do anything inside the block implementation'.
  • The query_loop_block_query_vars filter name is accurately documented and matches the firing site at the end of build_query_vars_from_query_block in src/wp-includes/blocks.php.
  • GAP: The query_loop_block_query_vars filter receives three arguments — $query (array), $block (WP_Block instance), and $page (int, current pagination page) — but the doc's filter description only mentions using it to 'modify your query' without explaining that $block->context['query'] is the way to read custom variation attributes like bookAuthor. Documenting the full callback signature and how to access custom query parameters via $block would significantly help developers implementing custom front-end queries.
