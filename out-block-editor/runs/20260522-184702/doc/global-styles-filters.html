Global Styles Filters

✅ No issues found.

Positives

  • The four filter hook names listed in the doc (wp_theme_json_data_default, wp_theme_json_data_blocks, wp_theme_json_data_theme, wp_theme_json_data_user) are all confirmed by the Hooks section firing sites in both wordpress-develop and gutenberg repos.
  • The doc correctly states that the filter callback receives an instance of WP_Theme_JSON_Data and that update_with( $new_data ) is the method to call — both the class and the method are confirmed in src/wp-includes/class-wp-theme-json-data.php.
  • GAP: WP_Theme_JSON_Data also exposes a get_data() method (returns the raw array) and a get_theme_json() method (added in 6.6.0, returns the underlying WP_Theme_JSON object). The doc only mentions update_with(), so developers who need read access to the current layer's data before modifying it are unaware of these two methods.
