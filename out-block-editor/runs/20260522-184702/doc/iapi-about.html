Positives

  • The doc's description of store() — that it accepts a namespace string, a storePart with state, actions, and callbacks, and returns stable references — accurately reflects the overloaded signatures and JSDoc in packages/interactivity/src/store.ts.
  • GAP: The store() function supports a third options parameter with a lock property (boolean or string) for creating private/locked namespaces. The doc page never mentions this capability, which is useful for plugin authors who want to prevent other code from extending their store namespace.
