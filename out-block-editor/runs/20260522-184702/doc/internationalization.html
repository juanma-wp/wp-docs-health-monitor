Positives

  • The doc correctly documents wp_set_script_translations() accepting an optional third $path argument — confirmed by the source: function wp_set_script_translations( $handle, $domain = 'default', $path = '' ) in src/wp-includes/functions.wp-scripts.php.
  • The doc accurately lists __(), _n(), and _x() as the common JS i18n functions, all of which are confirmed as real exports in packages/i18n/src/default-i18n.ts.
  • GAP: The @wordpress/i18n package also exports _nx() (plural with context) and hasTranslation(), neither of which is mentioned in the doc's list of common functions. Developers needing context-aware plurals or translation existence checks would benefit from knowing these exist.
