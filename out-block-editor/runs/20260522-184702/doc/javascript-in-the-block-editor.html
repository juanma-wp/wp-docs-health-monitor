Positives

  • The doc correctly states that wp_enqueue_script with enqueue_block_editor_assets is the right hook for block editor scripts — the source code confirms do_action( 'enqueue_block_editor_assets' ) fires in edit-form-blocks.php, site-editor.php, and widgets-form-blocks.php.
  • The doc's example of wp.blocks.registerBlockVariation is backed by the exported registerBlockVariation function in packages/blocks/src/api/registration.ts, and the global wp.blocks namespace is populated from that package — the usage pattern is correct.
  • GAP: The wp_enqueue_script $args parameter now accepts strategy ('defer'/'async'), fetchpriority, and module_dependencies array keys (added in WP 6.3–7.0). The doc's enqueue example only passes a boolean false as the last argument (the old $in_footer style), which still works but misses the opportunity to document the modern array-based $args API that developers would benefit from knowing about.
