Positives

  • The useEntityProp hook signature documented as useEntityProp('postType', postType, 'meta') returning [value, setter, fullValue] is accurate: the source confirms the hook accepts (kind, name, prop, _id) and returns [value, setValue, fullValue].
  • The register_post_meta PHP example correctly passes show_in_rest: true and single: true; the source confirms these are valid arguments forwarded to register_meta() via register_post_meta().
  • GAP: useEntityProp accepts an optional fourth parameter _id (an entity ID to use instead of the context-provided one), which the documentation never mentions. This lets block authors read/write meta for a specific post ID rather than the nearest context entity — useful for blocks that reference other posts.
