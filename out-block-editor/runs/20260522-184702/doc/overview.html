Positives

  • The doc correctly states that themes may disable the Widgets Block Editor using remove_theme_support( 'widgets-block-editor' ), which is consistent with the remove_theme_support() function in theme.php — the function does not block 'widgets-block-editor' (only 'editor-style', 'widgets', and 'menus' are protected from removal).
  • The doc accurately describes the Legacy Widget block as the compatibility mechanism for classic widgets, which aligns with the code's approach of storing blocks via an underlying 'Block' widget while keeping classic widgets accessible.
  • GAP: The add_theme_support() function in theme.php documents a widgets-block-editor feature (added in 5.8.0) that can also be used to *enable* the Widgets Block Editor explicitly, but the doc only mentions remove_theme_support() for disabling it — developers who want to explicitly opt in (e.g., after a child theme removes it) would benefit from knowing add_theme_support( 'widgets-block-editor' ) is the counterpart.
