Positives

  • The example correctly imports PluginPostStatusInfo from @wordpress/editor (not the deprecated @wordpress/edit-post version), which matches the canonical export confirmed in the source code.
  • GAP: The PluginPostStatusInfo exported from @wordpress/edit-post is deprecated since 6.6 (calls deprecateSlot('PluginPostStatusInfo') with alternative: 'wp.editor.PluginPostStatusInfo'), but the documentation page contains no deprecation notice or version note warning developers away from the @wordpress/edit-post import path.
  • GAP: registerPlugin silently falls back to the pluginsIcon default when no icon is provided (plugins[ name ] = { name, icon: pluginsIcon, ...settings }), but the documentation example and the PluginPostStatusInfo page never mention this default icon behaviour, which could surprise developers customising plugin appearance.
