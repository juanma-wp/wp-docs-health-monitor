Positives

  • The doc correctly distinguishes between synced and unsynced patterns, accurately describing that unsynced patterns become detached from the original after insertion — consistent with how the block editor handles pattern insertion.
  • The doc's guidance on template part updates (users who have modified templates won't receive theme updates) accurately reflects the WordPress template resolution logic, where user-saved templates in the database take precedence over theme files.
  • GAP: The doc uses the older term 'Reusable blocks' throughout (e.g., 'rely on reusable blocks or template parts'), but WordPress 6.3+ renamed these to 'Synced Patterns' — the doc inconsistently uses both terms, which could confuse developers looking for the feature in the UI.
