Positives

  • The doc correctly documents wp_interactivity_state as accepting an optional namespace and optional state array, matching the actual PHP signature function wp_interactivity_state( ?string $store_namespace = null, array $state = array() ): array.
  • The doc correctly documents wp_interactivity_config for passing static/non-reactive data (URLs, nonces) and getConfig() on the client side, both of which exist in the source with matching signatures.
  • GAP: wp_interactivity_get_element() (added in 6.7.0) is not mentioned anywhere in this doc page. It returns the current element being processed (including its attributes) and would be useful to developers writing derived state callbacks or directive processors that need to inspect the current HTML element.
