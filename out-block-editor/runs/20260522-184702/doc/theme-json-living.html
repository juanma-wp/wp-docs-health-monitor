Positives

  • The documentation accurately lists all settings.spacing.units default values as ["px","em","rem","vh","vw","%"], which matches the schema's "default": [ "px", "em", "rem", "vh", "vw", "%" ] exactly.
  • The documentation correctly documents settings.spacing.blockGap as type boolean, null with default null, matching the schema's oneOf: [boolean, null] with "default": null.
  • GAP: The schema's settings.typography.textIndent constrains the string enum to only "subsequent" and "all", and the boolean to only false — but the doc's Type column shows the generic boolean, string without conveying these constraints. A theme author setting textIndent: true or textIndent: "custom" would produce an invalid theme.json that fails schema validation.
