Migrating Theme.json to Newer Versions

https://developer.wordpress.org/block-editor/reference-guides/theme-json-reference/theme-json-migrations/
100 healthy

✅ No issues found.

Positives

  • The v2→v3 migration guidance for settings.typography.defaultFontSizes correctly identifies the default slugs (small, medium, large, x-large, xx-large) and accurately describes the true-by-default behaviour, which matches the schema's "default": true for defaultFontSizes.
  • The v2→v3 migration guidance for settings.spacing.defaultSpacingSizes correctly identifies the default slugs (20, 30, 40, 50, 60, 70, 80) and accurately describes the true-by-default behaviour, consistent with the schema's "default": true for defaultSpacingSizes.
  • GAP: The schema defines settings.spacing.spacingScale with a steps property that has a minimum: 1 constraint, meaning { "steps": 0 } used as an example in the migration guide is technically invalid per the schema (minimum is 1). Theme authors following the doc's example of setting spacingScale to { "steps": 0 } to disable default spacing sizes in v2 may encounter schema validation errors.
