Fix the textdomain in the initial Edit() function example shown in the 'Updating edit.js' section.

  • Change 'copyright-date-block-demo' to 'copyright-date-block' in the __() call to match the textdomain declared in block.json.
  • The surrounding prose describes this snippet as showing the scaffolded file's default message, so the textdomain should match the block's actual textdomain.

Positives

  • The tutorial correctly documents that useBlockProps() must be used on the outermost element of a block's Edit component, which matches the code's JSDoc: 'Use of this hook on the outermost element of a block is required if using API >= v2.'
  • The tutorial accurately shows useBlockProps.save() (not useBlockProps()) for the save function's wrapper element, which correctly reflects the code where useBlockProps.save = getBlockProps is a separate static method.
  • GAP: The TextControl component's __next40pxDefaultSize prop is shown in the first TextControl example but is silently dropped in the later 'Updating the block content' section's final Edit() function listing — developers copy-pasting the final complete example will get the deprecated 36px size warning since __next40pxDefaultSize is missing from the TextControl in that final snippet.
