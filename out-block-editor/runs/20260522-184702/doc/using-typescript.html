Positives

  • The doc correctly describes AsyncAction<T> as matching Generator<any, T, unknown> and accurately explains that generator-based async actions are inferred as Promise-returning functions in the store's type — this matches the ConvertGeneratorToPromise type in store.ts.
  • The doc's explanation of getContext<T>() accepting a generic type parameter is accurate — the source in scopes.ts exports getContext = <T extends object>(namespace?: string): T => ..., confirming the generic usage shown in all examples.
  • GAP: The store() function accepts a lock option (StoreOptions.lock?: boolean | string) that allows namespaces to be made private or shared only with callers who know the lock string. This is a meaningful capability for plugin authors but is never mentioned in the TypeScript guide or cross-referenced from it.
