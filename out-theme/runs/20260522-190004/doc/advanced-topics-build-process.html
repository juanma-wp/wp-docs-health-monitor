Positives

  • The wp_enqueue_script() call in the PHP example correctly passes true as the last ($args/in_footer) argument for the editor script, which matches the function signature in functions.wp-scripts.php where a boolean is accepted and treated as in_footer.
  • The wp_enqueue_style() calls in the PHP example correctly pass $asset['dependencies'] and $asset['version'] as the third and fourth parameters, matching the $deps and $ver positions in wp_enqueue_style() as defined in functions.wp-styles.php.
  • GAP: The webpack-remove-empty-scripts plugin's STAGE_AFTER_PROCESS_PLUGINS constant is used in the doc's webpack config example but is never explained. Developers would benefit from a note that this stage constant ensures the .asset.php files generated by @wordpress/scripts are written before the empty JS files are removed.
