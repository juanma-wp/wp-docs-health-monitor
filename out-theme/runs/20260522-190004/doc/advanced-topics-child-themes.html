Child Themes

✅ No issues found.

Positives

  • The doc correctly states that load_child_theme_textdomain() should be used instead of load_theme_textdomain() for child themes — both functions exist in src/wp-includes/l10n.php with the expected signatures, and load_child_theme_textdomain() internally delegates to load_theme_textdomain() using get_stylesheet_directory() as the default path, which is exactly the child-theme-specific behaviour the doc describes.
  • The doc correctly identifies get_theme_file_path() for including PHP files and get_theme_file_uri() for referencing files by URL — both functions exist in src/wp-includes/link-template.php and search the stylesheet (child) directory before the template (parent) directory, matching the doc's description of child-theme-aware file resolution.
  • GAP: get_parent_theme_file_path() exists in src/wp-includes/link-template.php and always resolves to the parent (template) directory. The doc only mentions get_parent_theme_file_uri() for URL references but never mentions get_parent_theme_file_path() for filesystem path references to parent-theme files — developers who need to require a parent-theme PHP file would benefit from knowing this function exists.
