Positives

  • The load_theme_textdomain() function signature documented as load_theme_textdomain( string $domain, string|false $path = false ): bool matches the source code exactly, including the false default for $path and the bool return type.
  • The doc correctly states that after_setup_theme is the right action hook for loading translations — the source code in wp-settings.php confirms do_action( 'after_setup_theme' ) fires after theme functions.php is loaded, making it the earliest safe point.
  • GAP: Since WordPress 6.7.0, load_theme_textdomain() no longer immediately loads translations but hands them off to the just-in-time loading mechanism (noted in the @since 6.7.0 tag in the source). The documentation does not mention this behaviour change, which affects developers who rely on translations being available immediately after calling the function.
