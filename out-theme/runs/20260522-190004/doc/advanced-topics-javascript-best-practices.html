Positives

  • The doc correctly explains that WordPress loads jQuery in noConflict() mode and provides the standard IIFE wrapper pattern ( function( $ ) { } )( jQuery ); — this is accurate and matches long-standing WordPress core behaviour.
  • The doc correctly advises using array( 'jquery' ) as a dependency when enqueuing scripts, which is the correct wp_enqueue_script() pattern for ensuring jQuery is loaded first.
  • GAP: The doc's 'Potentially removed APIs' list flags .bind and .click as possibly removed — these are indeed deprecated jQuery methods (as of jQuery 3.0, .bind() is deprecated in favour of .on()). The doc uses .bind in prose as an example of event-binding methods but does not warn developers that .bind() is deprecated in the version of jQuery bundled with WordPress (3.x), which could lead developers to adopt a deprecated API.
