Positives

  • The doc correctly states that get_theme_file_path() searches the child theme's stylesheet directory before the parent theme's template directory — this matches the code in get_theme_file_path() which checks $stylesheet_directory !== $template_directory && file_exists( $stylesheet_directory . '/' . $file ) before falling back to $template_directory.
  • The doc correctly identifies after_setup_theme as the appropriate hook for the theme setup function, matching src/wp-settings.php which fires do_action( 'after_setup_theme' ) immediately after loading functions.php files.
  • GAP: The doc does not mention that get_theme_file_path() and get_theme_file_uri() both apply filterable hooks (theme_file_path and theme_file_uri respectively), which allows plugins or child themes to override the resolved path/URL programmatically — a useful capability for theme developers.
