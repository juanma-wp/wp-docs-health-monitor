Positives

  • The doc's list of top-level theme.json properties ($schema, version, settings, styles, customTemplates, templateParts, patterns) matches the schema's top-level structure exactly — no phantom or missing keys.
  • The appearanceTools example snippet correctly uses "version": 2 and the schema URL https://schemas.wp.org/trunk/theme.json, consistent with the schema file.
  • GAP: The schema defines a settings.spacing.blockGap property whose default is null (not false), and the distinction between false and null has meaningful behavioral differences (null further disables layout styles). The doc does not mention this property or its nuanced default at all, which could mislead developers configuring spacing.
