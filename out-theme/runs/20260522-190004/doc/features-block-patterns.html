query (use posts instead)

wordpress-develop:src/wp-includes/block-patterns.php

register_block_pattern_category(
		'query',
		array(
			'label'       => _x( 'Posts', 'Block pattern category' ),
			'description' => __( 'Display your latest posts in lists, grids or other layouts.' ),
		)
	);
💡

Remove the "(use posts instead)" deprecation note from the query category entry. Both query and posts are actively registered as core block pattern categories in _register_core_block_patterns_and_categories(). The query category is not deprecated or removed — developers following the doc's advice to avoid it would be misled into abandoning a valid, still-registered category.

  • In the block pattern categories table/list, change the query entry from "query (use posts instead)" to simply "query", with its label "Posts" and description "Display your latest posts in lists, grids or other layouts."
  • If posts was introduced as a preferred replacement at a specific version, add a "Since X.X" note rather than implying query is gone.
