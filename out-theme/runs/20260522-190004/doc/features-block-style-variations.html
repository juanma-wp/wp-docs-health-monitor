Positives

  • The doc correctly states that register_block_style() returns true or false, matching the PHP source: return WP_Block_Styles_Registry::get_instance()->register( $block_name, $style_properties ); which returns bool.
  • The JavaScript wp.domReady pattern shown for unregistering block styles is accurate — the code confirms wp.domReady is a real hook fired after DOM load, and the wp.blocks.unregisterBlockStyle() function exists in the exported API.
  • GAP: The PHP register_block_style() function has supported registering styles for multiple block types simultaneously (passing an array as $block_name) since WordPress 6.6.0, but the doc's PHP signature and example only show a single string. Developers who need to register the same style for multiple blocks at once would not know this is possible.
