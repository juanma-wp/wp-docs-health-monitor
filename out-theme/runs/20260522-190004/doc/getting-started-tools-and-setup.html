Positives

  • The doc correctly identifies @wordpress/env as a local WordPress environment package and links to the official Block Editor Handbook — this matches the actual npm package name and its documented purpose.
  • The Monster Widget plugin entry correctly notes it is for 'classic themes only', which is accurate since block themes use block-based widgets and do not use the classic widget system.
  • GAP: The doc lists Brackets (https://brackets.io/) as a popular free/open-source editor, but Brackets was archived/discontinued in 2021 and its successor (maintained fork) is now 'Brackets-cont'. Developers following this link may find the project is no longer actively maintained, though the link itself still resolves.
