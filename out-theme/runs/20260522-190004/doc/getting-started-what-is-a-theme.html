Positives

  • The doc correctly distinguishes block themes (HTML-based templates, theme.json, Site Editor) from classic themes (PHP-based templating), which aligns with the well-established WordPress theming architecture.
  • The doc accurately notes that hybrid themes are classic themes that have adopted block-related features like global settings/styles or block template parts — this is a precise and correct characterisation of the hybrid pattern.
  • GAP: The doc mentions that themes can be exported directly from the Site Editor, but does not mention the create-block-theme plugin or the programmatic wp_theme_get_post_templates() / related APIs that developers might use to automate theme export workflows — useful context for developers wanting to go beyond manual export.
