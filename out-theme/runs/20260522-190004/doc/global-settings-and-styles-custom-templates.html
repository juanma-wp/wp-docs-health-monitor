Positives

  • The doc correctly identifies all three supported properties of a customTemplates entry (name, title, postTypes) — these align with the theme.json schema's customTemplates definition.
  • The doc accurately states that postTypes is optional and defaults to the page post type, which is consistent with standard WordPress theme.json behaviour for this field.
  • GAP: The theme.json schema supports a version field at the top level (the doc example uses "version": 2), but the doc does not mention that newer theme.json versions (e.g., version 3) may be available or recommended, which could matter for developers targeting newer WordPress releases.
