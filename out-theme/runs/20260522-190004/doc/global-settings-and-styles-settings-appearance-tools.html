Appearance Tools

100 healthy

✅ No issues found.

Positives

  • The doc correctly states that settings.appearanceTools defaults to false, which matches the schema: "default": false in settingsAppearanceToolsProperties.
  • The doc correctly explains that individual properties can override appearanceTools (e.g., setting position.sticky: false after enabling appearanceTools: true), which is consistent with how theme.json property merging works.
  • GAP: The schema shows appearanceTools also enables background: backgroundImage, backgroundSize, color: heading, button, caption, and additional dimensions properties (aspectRatio, height, minWidth, width) — none of which are mentioned in the doc's equivalent-settings example. Developers relying on the doc's list would have an incomplete picture of what appearanceTools activates.
