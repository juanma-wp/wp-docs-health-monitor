💡

Update the settings.dimensions documentation to remove the claim that it "only lets you set a single property" and list all supported sub-properties.

  • Remove the sentence "Currently, it only lets you set a single property" — the dimensions object has 8 sub-properties.
  • Add aspectRatio (boolean, default: false) — Allow users to set an aspect ratio.
  • Add defaultAspectRatios (boolean, default: true) — Allow users to choose aspect ratios from the default set.
  • Add aspectRatios (array) — Allow users to define custom aspect ratio presets (each with name, slug, and ratio).
  • Add height (boolean, default: false) — Allow users to set custom height.
  • Add minHeight (boolean, default: false) — Allow users to set custom minimum height.
  • Add minWidth (boolean, default: false) — Allow users to set custom minimum width.
  • Add width (boolean, default: false) — Allow users to set custom width.
  • Add dimensionSizes (array) — Dimension size presets that generate --wp--preset--dimension--{slug} custom properties.

Positives

  • The doc correctly states that settings.dimensions.minHeight is a boolean with a default value of false, which matches the schema: "minHeight": { "type": "boolean", "default": false }.
  • GAP: The schema defines settings.dimensions.aspectRatio, height, minWidth, width, aspectRatios, defaultAspectRatios, and dimensionSizes — none of which are mentioned in the documentation. Theme developers who rely solely on this page would be unaware of these controls and unable to use them.
  • GAP: The appearanceTools setting (schema: settingsAppearanceToolsProperties) lists dimensions: aspectRatio, height, minHeight, minWidth, width as properties it enables in bulk — the doc never mentions that appearanceTools: true can activate dimension controls as an alternative to setting them individually.
