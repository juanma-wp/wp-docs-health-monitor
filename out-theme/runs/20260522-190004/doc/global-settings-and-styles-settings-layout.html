Positives

  • The two documented sub-properties of settings.layout — contentSize and wideSize — exactly match the property names defined in the schema's settingsLayoutProperties definition, confirming the doc's property names are correct.
  • The doc's example JSON snippets use "version": 2 at the top level, which is consistent with the theme.json schema structure shown in the source.
  • GAP: The schema defines two additional settings.layout properties not mentioned in the doc — allowEditing (disables layout UI controls, default: true) and allowCustomContentAndWideSize (enables/disables custom content and wide size controls, default: true) — which theme developers would benefit from knowing about.
