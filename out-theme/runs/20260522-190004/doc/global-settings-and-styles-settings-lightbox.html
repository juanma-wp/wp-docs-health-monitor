Positives

  • The doc correctly identifies both enabled and allowEditing as the two nested properties of the lightbox object, matching the schema's settingsLightboxProperties definition which lists exactly those two properties.
  • The doc's statement that allowEditing defaults to true is consistent with the schema, which defines allowEditing as a boolean with no explicit default field — however, the schema also omits a default for enabled, which aligns with the doc's claim that enabled defaults to undefined.
  • GAP: The schema shows lightbox is available under settingsPropertiesComplete, meaning it can technically be set at the global settings level (not just under settings.blocks.core/image), but the doc only demonstrates block-level usage. Theme authors may not realise they can set a global lightbox default.
