Positives

  • The doc correctly states that settings.position.sticky defaults to false, which matches the schema: "sticky": { "type": "boolean", "default": false }.
  • The doc accurately describes settings.position as containing only a single property (sticky), consistent with the schema's settingsPositionProperties definition which lists only sticky under position.properties.
  • GAP: The appearanceTools setting (documented in the schema as enabling position: sticky among other features) is not mentioned on this page. Developers who want to enable sticky positioning alongside other appearance tools via a single flag would benefit from knowing that setting appearanceTools: true also enables settings.position.sticky.
