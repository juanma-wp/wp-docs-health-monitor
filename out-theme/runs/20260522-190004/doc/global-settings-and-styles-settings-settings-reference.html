gutenberg:schemas/json/theme.json

"defaultFontSizes": {
							"description": "Allow users to choose font sizes from the default font size presets.",
							"type": "boolean",
							"default": true
						}
💡

Add defaultFontSizes to the settings.typography property table in the documentation.

  • Add a row for defaultFontSizes with type boolean, default true, and description: "Allow users to choose font sizes from the default font size presets."
  • Place it alongside the other boolean typography toggles such as customFontSize, fontStyle, fontWeight, etc.

Positives

  • The settings.border sub-properties (color, radius, style, width) and their defaults are accurately documented and match the schema's settingsBorderProperties definition.
  • The settings.spacing.units default value [ "px", "em", "rem", "vh", "vw", "%" ] is correctly documented and matches the schema's default array exactly.
  • GAP: settings.border.radiusSizes (array <object>, props: name, slug, size) exists in the schema but is not documented in the settings.border table — theme authors could use this to define border-radius presets that generate --wp--preset--border-radius--{slug} custom properties.
