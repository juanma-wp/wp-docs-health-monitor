Positives

  • The documentation correctly describes letterSpacing default as false in the prose but the code example shows true — the schema confirms true is the actual default, making this a clear drift. The doc's example JSON block (which shows "letterSpacing": true) is actually correct; only the prose description is wrong.
  • The fontFace required fields (fontFamily and src) are accurately documented: the schema confirms "required": [ "fontFamily", "src" ], consistent with the doc listing them without a Required marker while the intro notes they are needed for web fonts.
  • GAP: The schema exposes a defaultFontSizes boolean property (settings.typography.defaultFontSizes, default true) that controls whether users can choose from the default font size presets. The documentation never mentions this property, which would be useful for theme authors who want to hide the default sizes entirely.
