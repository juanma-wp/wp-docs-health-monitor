Positives

  • The documentation correctly lists lightbox as a valid settings property and links to its documentation page — this matches the schema's settingsLightboxProperties definition and its inclusion in settingsPropertyNames.
  • The documentation accurately describes appearanceTools as a boolean with a default of false, which matches the schema: "type": "boolean", "default": false.
  • GAP: The background settings group (settings.background.backgroundImage, settings.background.backgroundSize, settings.background.gradient) is a fully defined top-level settings property in the schema (settingsBackgroundProperties) but is entirely absent from both the example JSON snippet and the settings documentation link list. Developers would not know this property exists.
