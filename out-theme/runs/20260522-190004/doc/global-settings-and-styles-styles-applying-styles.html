Applying Styles

✅ No issues found.

Positives

  • The doc correctly describes that styles.blocks.core/button.variations accepts named variation keys (e.g., outline, fill) — this matches the schema's patternProperties pattern ^[a-z][a-z0-9-]*$ under stylesBlocksPropertiesComplete for core/button.
  • The doc accurately states that button and link elements support pseudo-classes while heading, caption, cite, and h1–h6 do not — this matches the schema where only button and link definitions include stylesElementsPseudoSelectorsProperties via allOf.
  • GAP: The schema supports a :focus-visible pseudo-class for both block-level (stylesBlocksPseudoSelectorsPropertyNames) and element-level (stylesElementsPseudoSelectorsPropertyNames) selectors, but the documentation never mentions :focus-visible as a supported pseudo-class. Developers building accessible themes would benefit from knowing this is available.
