Positives

  • The border section correctly documents both the shorthand (all-sides) and per-side (top, right, bottom, left) sub-properties, matching the schema's stylesProperties.border definition exactly.
  • The shadow style property is accurately documented as a top-level string (not nested), matching the schema's "shadow": { "oneOf": [{ "type": "string" }, ...] } definition.
  • GAP: The schema defines styles.color.gradient (sets the background CSS property via a gradient value), but the documentation's Color section omits this property entirely — developers who want to set a gradient via styles would not know it exists.
