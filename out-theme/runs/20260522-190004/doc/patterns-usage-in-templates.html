✅ No issues found.

Positives

  • The doc correctly describes the Pattern block markup syntax (<!-- wp:pattern {"slug":"namespace/pattern-slug"} /-->) and its slug parameter, which aligns with how the Pattern block is used in WordPress core block templates.
  • The doc accurately explains that the Pattern block is not surfaced in the block inserter UI and is primarily intended for theme template use — this is consistent with the block's design in WordPress core.
  • GAP: The doc does not mention that patterns registered with Inserter: false in their file header will be hidden from the block inserter but still usable via wp:pattern in templates — a useful distinction for theme authors who want template-only patterns.
