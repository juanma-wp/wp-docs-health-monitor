Positives

  • The doc correctly describes useBlockProps.save() as the static method to call inside save functions, which matches useBlockProps.save = getBlockProps in the source.
  • The doc accurately states that useBlockProps requires API version 2 or higher, matching the source warning: Block type must support API version 2 or higher to work correctly with "useBlockProps" method.
  • GAP: useBlockProps accepts a second internal { __unstableIsHtml } options argument (visible in the source signature useBlockProps( props = {}, { __unstableIsHtml } = {} )). While this is intentionally unstable/internal, the doc makes no mention of the two-argument form at all, which could confuse developers reading the source.
