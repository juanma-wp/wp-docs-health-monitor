Positives

  • The doc correctly lists TextControl, Panel, ToggleControl, and ExternalLink as components from @wordpress/components — all four are confirmed exports in the source files.
  • The doc's Edit function example correctly uses useBlockProps() and destructures attributes, setAttributes from props, which matches the native Edit component pattern in packages/block-editor/src/components/block-edit/edit.native.js that passes all props through to the block's edit component.
  • GAP: The RichText component (native) exposes a preserveWhiteSpace prop used in createRecord and formatToValue, but the doc does not mention it. Block authors using RichText for preformatted content would benefit from knowing this prop exists.
