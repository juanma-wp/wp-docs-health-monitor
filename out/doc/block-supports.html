Positives

  • The dimensions subproperties (aspectRatio, height, minHeight, minWidth, width) and their default values of false are accurately documented and match the schema definitions in schemas/json/block.json.
  • The color subproperty defaults are correctly documented: background and text default to true, while gradients, link, heading, button default to false, and enableContrastChecker defaults to true — all matching the schema.
  • GAP: The background.gradient subproperty exists in the schema (schemas/json/block.json under supports.background) but is not documented in the ## background section. Developers who want to enable gradient support via the background support object would not know this option exists.
