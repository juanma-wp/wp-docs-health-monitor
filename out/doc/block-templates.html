Positives

  • The templateLock options (contentOnly, all, insert) documented in the Locking section are accurately described: contentOnly is correctly noted as non-overridable by children, distinguishing it from the other lock types.
  • The nested template PHP example correctly demonstrates the three-element array structure [ block-name, attributes, inner-blocks ] for container blocks like core/columns and core/column, which matches the expected block template format.
  • GAP: The doc does not mention that templateLock on an InnerBlocks area also accepts 'contentOnly' as a JS prop value (not just as a PHP template_lock string), which is important for block authors using InnerBlocks in JS who want content-only locking.
