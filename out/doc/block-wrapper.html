The block wrapper

100 healthy

✅ No issues found.

Positives

  • The doc correctly states that useBlockProps.save() is the client-side equivalent of get_block_wrapper_attributes() for the save function — both are confirmed in source: useBlockProps.save = getBlockProps in use-block-props/index.js and function get_block_wrapper_attributes( $extra_attributes = array() ) in class-wp-block-supports.php.
  • The doc accurately describes that useBlockProps() adds data-block, data-type, data-title, role='document', and aria-label attributes — all confirmed present in the return value of useBlockProps() in use-block-props/index.js.
  • GAP: The doc does not mention that useBlockProps() requires API version >= 2 to work correctly. The source code emits a warning (Block type must support API version 2 or higher) when blockApiVersion < 2, and the JSDoc explicitly states: "Use of this hook on the outermost element of a block is required if using API >= v2." Developers using API v1 blocks would be silently broken without this information.
