Positives

  • The withSyncEvent() documentation accurately describes its purpose, required use cases (event.preventDefault, event.stopPropagation, event.stopImmediatePropagation, event.currentTarget), and the generator function combination pattern — all of which match the source implementation in packages/interactivity/src/utils.ts.
  • The watch() function documentation correctly describes it as returning a cleanup (unwatch) function and supporting a cleanup return from the callback — consistent with export const watch = effect in index.ts (Preact's effect API).
  • GAP: The getElement() documentation does not mention that attributes is a deeply read-only proxy in debug mode (SCRIPT_DEBUG), and that attempting to mutate it will emit a warning. Developers who try to modify element.attributes directly will be silently blocked in production or warned in development, which could be surprising.
