Positives

  • The doc correctly describes the namespace attribute as a special Query Loop attribute used purely for variation scoping — this matches the code in build_query_vars_from_query_block() which never reads namespace itself, confirming it is purely a convention for extenders.
  • The isActive array shorthand (e.g. isActive: [ 'namespace' ]) is accurately documented as an alternative to the function form — the block.json schema confirms isActive accepts an array of strings for attribute comparison.
  • GAP: The query_loop_block_query_vars filter receives a third argument $page (the current page integer) that the doc never mentions. Developers implementing pagination-aware custom queries (e.g. offset calculations) would need this value and would be surprised to find it undocumented.
