Positives

  • The four filter hook names (wp_theme_json_data_default, wp_theme_json_data_blocks, wp_theme_json_data_theme, wp_theme_json_data_user) are all confirmed correct by the Hooks section, which shows all four apply_filters() calls in both wordpress-develop and gutenberg repos.
  • The update_with( $new_data ) method name and its parameter are accurately documented — the code in class-wp-theme-json-data.php confirms public function update_with( $new_data ) exists and returns WP_Theme_JSON_Data (the own instance), exactly as described.
  • GAP: The WP_Theme_JSON_Data class also exposes a get_data() method (returns the raw array) and a get_theme_json() method (added in 6.6.0, returns the underlying WP_Theme_JSON object). Neither is mentioned in the documentation, but both are useful to developers who want to inspect or further manipulate the data inside a filter callback.
