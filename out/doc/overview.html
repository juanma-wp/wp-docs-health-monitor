Positives

  • The doc correctly states that themes may disable the Widgets Block Editor using remove_theme_support( 'widgets-block-editor' ), which is consistent with the remove_theme_support() function in the source — widgets-block-editor is listed as a valid feature in add_theme_support() and is not in the protected list that remove_theme_support() guards against.
  • The doc accurately describes the Legacy Widget block as the compatibility mechanism for classic widgets, which aligns with the code's handling of widget areas and the widgets-block-editor theme support feature added in 5.8.0.
  • GAP: The add_theme_support() source documents that widgets-block-editor was added in 5.8.0 (@since 5.8.0 The widgets-block-editor feature enables the Widgets block editor), but the documentation page does not mention the minimum WordPress version required to use the Widgets Block Editor. Developers targeting older WordPress installs would benefit from knowing this feature requires WP 5.8+.
