Positives

  • The doc correctly distinguishes between synced and unsynced patterns, accurately noting that unsynced patterns become detached from the original after insertion — this matches the core WordPress block editor behaviour.
  • The doc accurately describes the template override mechanism: user-edited templates take precedence over theme file updates, which is consistent with how WordPress resolves template hierarchy from the database vs. filesystem.
  • GAP: The doc uses the term 'Reusable blocks' throughout (e.g., 'rely on reusable blocks or template parts'), but WordPress 6.3+ renamed this feature to 'Synced Patterns'. The doc inconsistently uses both terms — 'Reusable block' in the Patterns section and 'Synced Patterns' as a separate heading — which may confuse developers about whether these are the same feature.
