Positives

  • The doc correctly documents wp_interactivity_state as accepting an optional $store_namespace and optional $state array, matching the actual PHP signature function wp_interactivity_state( ?string $store_namespace = null, array $state = array() ): array.
  • The doc correctly documents wp_interactivity_config with its $store_namespace and optional $config parameters, and the getConfig() JS client counterpart, both of which exist exactly as described in the source.
  • GAP: wp_interactivity_get_element() (added in 6.7.0) is not mentioned anywhere in the documentation. It returns an array representation of the current element being processed (including its attributes) and is useful inside derived state getters or callbacks that need to inspect the current DOM element during server-side directive processing.
