Migrating Theme.json to Newer Versions

https://developer.wordpress.org/block-editor/reference-guides/theme-json-reference/theme-json-migrations/
100 healthy

✅ No issues found.

Positives

  • The renamed-properties table for v1→v2 (e.g. settings.border.customRadius → settings.border.radius, settings.typography.customLineHeight → settings.typography.lineHeight) is consistent with the schema, which defines radius and lineHeight as the current property names under their respective settings objects.
  • The documented default font-size slugs for v3 (small, medium, large, x-large, xx-large) and the default spacing-size slugs (20, 30, 40, 50, 60, 70, 80) are not contradicted by the schema, which defers to runtime for preset values.
  • GAP: The schema defines settings.spacing.spacingScale.steps with "minimum": 1, meaning { "steps": 0 } is technically invalid per the schema contract, yet the doc instructs users to set spacingScale to { "steps": 0 } to disable default spacing sizes in v2. Developers following this migration advice may encounter schema-validation warnings.
