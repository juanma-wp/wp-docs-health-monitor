Update the settings.dimensions property table to include all schema-defined properties that are currently missing.

  • Add a row for defaultAspectRatios (type: boolean, default: true) — allows users to choose from the default set of aspect ratios.
  • Add a row for aspectRatios (type: array) — allows users to define custom aspect ratio presets.
  • Add a row for height (type: boolean, default: false) — allows users to set custom height.
  • Add a row for minWidth (type: boolean, default: false) — allows users to set custom minimum width.
  • Add a row for width (type: boolean, default: false) — allows users to set custom width.
  • Add a row for dimensionSizes (type: array) — dimension size presets that generate --wp--preset--dimension--{slug} custom properties.

Positives

  • The settings.spacing table accurately documents all core properties (blockGap, margin, padding, units, customSpacingSize, spacingSizes, spacingScale) with correct types and defaults matching the schema, including the nuanced blockGap type of boolean, null with default null.
  • The settings.typography table correctly documents the fluid property as object, boolean with default false, matching the schema's oneOf definition combining an object shape and a boolean type.
  • GAP: The schema defines settings.spacing.defaultSpacingSizes (boolean, default true) which is entirely absent from the settings.spacing property table. Theme authors who want to hide the default spacing size presets would not know this control exists.
