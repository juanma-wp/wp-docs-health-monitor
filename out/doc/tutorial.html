Positives

  • The tutorial correctly documents that useBlockProps() is required on the outermost element of a block when using API v2 or higher — this matches the code comment in packages/block-editor/src/components/block-list/use-block-props/index.js: 'Use of this hook on the outermost element of a block is required if using API >= v2.'
  • The tutorial correctly shows useBlockProps.save() (not useBlockProps()) for the save function's wrapper props, which matches the code: useBlockProps.save = getBlockProps; in index.js.
  • GAP: The TextControl component accepts a __next40pxDefaultSize prop that opts into the updated 40px default size. The tutorial's final consolidated Edit() function example (in the 'Updating the block content' section) drops __next40pxDefaultSize from the TextControl inside the toggle-conditional branch, even though it was present in the earlier step. Developers copying the final snippet will get a deprecation warning in the console.
