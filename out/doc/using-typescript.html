Positives

  • The doc correctly describes AsyncAction<T> as a generator type and accurately shows that the store function's type inference converts generator functions to Promise-returning async functions in the returned type — this matches the ConvertGeneratorsToPromises type utility in store.ts.
  • The doc correctly describes TypeYield<T> as resolving to the type that the promise fulfills with, matching export type TypeYield< T extends ( ...args: any[] ) => Promise< any > > = Awaited< ReturnType< T > > in store.ts.
  • GAP: The store function accepts a lock option (StoreOptions.lock?: boolean | string) that allows namespaces to be made private or semi-private with a lock string. This is a meaningful capability for plugin authors wanting to protect their store namespace, but the TypeScript guide never mentions it.
